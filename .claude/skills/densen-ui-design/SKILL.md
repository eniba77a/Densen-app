# DENSEN UI Design Guardian

## Goal

Maintain a consistent premium visual identity across the entire DENSEN application.

DENSEN should feel like a professional global dance platform rather than a generic AI-generated web application.

## Visual Direction

DENSEN uses:

- Premium modern minimalism
- Dark charcoal and near-black foundations
- Elegant gold accents
- White and light typography
- Strong visual hierarchy
- Modern rounded cards
- Cinematic dance imagery
- High-quality dance video
- Subtle smooth animations
- Clean spacing
- Mobile-first layouts
- Sophisticated interactions

## Avoid

Do not introduce:

- Generic SaaS styling
- Childish interfaces
- Excessive glassmorphism
- Excessive gradients
- Neo-brutalist styling
- Random colors
- Cluttered layouts
- Excessive borders
- Inconsistent typography
- Unnecessary animations
- Desktop-first designs

## Workflow

1. Inspect existing DENSEN components before creating new UI.
2. Reuse existing components where appropriate.
3. Preserve established typography.
4. Preserve established spacing.
5. Preserve established buttons and interaction patterns.
6. Preserve established navigation.
7. Use existing design tokens when available.
8. Maintain consistent visual hierarchy.
9. Design mobile-first.
10. Ensure responsive behavior on tablet and desktop.
11. Provide loading, empty, error, and success states.
12. Maintain accessible text contrast.
13. Ensure interactive elements have comfortable touch targets.
14. Keep dance video and visual content prominent.

## Dance-Focused UX

DENSEN is not a generic social network.

The interface should prioritize:

- Dance videos
- Learning
- Practice
- Choreography
- Teachers
- Challenges
- Dance discovery
- Community

When choosing between a generic social interaction and a dance-specific interaction, prefer the DENSEN dance experience.

## Final Check

Before completing UI work:

- Check mobile layout.
- Check desktop layout.
- Check typography.
- Check spacing.
- Check navigation.
- Check loading and empty states.
- Check accessibility.
- Confirm the new screen visually belongs to DENSEN.
- Avoid unnecessary redesign of existing screens.
