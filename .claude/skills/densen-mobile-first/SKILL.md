# DENSEN Mobile First Guardian

## Goal

Ensure DENSEN provides an excellent mobile experience because the platform is primarily designed for dancers using phones.

## Workflow

1. Design mobile-first.
2. Check common Android and iOS screen sizes.
3. Check portrait layouts.
4. Check responsive behavior on tablets and desktop.
5. Verify touch interactions.
6. Verify buttons and controls have comfortable touch targets.
7. Verify navigation remains accessible.
8. Verify videos scale correctly.
9. Verify media does not overflow the screen.
10. Verify forms and keyboards do not hide important controls.
11. Check safe areas and device notches where relevant.
12. Check performance and unnecessary animations.

## Video Experience

DENSEN relies heavily on dance video.

Ensure:

- Videos fit the viewport correctly.
- Controls remain usable.
- Full-screen experiences work correctly.
- Loading states are clear.
- Videos do not cause layout jumps.
- Video-heavy screens remain usable on slower connections.

## Responsive Rules

Avoid:

- Horizontal scrolling
- Tiny touch targets
- Desktop-only interactions
- Hover-only functionality
- Fixed elements covering important content
- Layouts that break on narrow screens

## Final Check

Before completing mobile UI work:

- Test narrow phone layout.
- Test larger phone layout.
- Test tablet layout.
- Test desktop layout.
- Check navigation.
- Check touch interactions.
- Check forms.
- Check video.
- Check loading states.
