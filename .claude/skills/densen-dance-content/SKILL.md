# DENSEN Dance Content Engineer

## Goal

Keep DENSEN's educational system focused on structured dance learning and progression.

## Core Content Types

DENSEN supports:

- Moves
- Combos
- Choreographies
- Lessons
- Classes
- Courses
- Challenges
- Practice

## Learning Flow

Use this general progression:

Discover → Learn → Practice → Complete → Record → Share

## Content Metadata

Where appropriate, dance content should support:

- Dance style
- Difficulty
- Level
- Teacher
- Duration
- Description
- Free or paid access
- Dance Credits
- Progress
- Completion
- Practice history
- Visibility
- Publishing status

## Workflow

1. Inspect existing dance-content models.
2. Reuse existing structures when possible.
3. Avoid duplicate content models.
4. Preserve relationships between teachers, students, classes, and content.
5. Support progress tracking.
6. Support completion states.
7. Respect free, paid, and credit-based access.
8. Respect copyright and music-rights metadata.
9. Respect privacy and age-based restrictions.

## Learning Experience

Dance content should be easy to:

- Discover
- Start
- Pause
- Practice
- Repeat
- Complete
- Save
- Share

## Final Check

Before completing dance-content work:

- Verify content metadata.
- Verify access permissions.
- Verify progress tracking.
- Verify completion.
- Verify teacher ownership where relevant.
- Verify mobile usability.
- Verify existing learning functionality still works.
